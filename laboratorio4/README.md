# Laboratorio 04 - Sprint 01

Entrega da Sprint 01 do Laboratorio 04: caracterizacao do dataset do projeto de TIS 6 utilizando os dados do banco PostgreSQL `youtube_research`.

## Arquivos

- `lab04s01_caracterizacao_dataset.md`: caracterizacao textual do dataset e roteiro dos graficos para o Power BI.
- `powerbi_caracterizacao_youtube_research.sql`: consultas SQL prontas para importar ou validar os dados no Power BI.

## Fonte dos dados

Os dados estao no container Docker `youtube-research-postgres-1`.

- Servidor: `localhost:55432`
- Banco: `youtube_research`
- Usuario: `yt`
- Senha: `ytsecret`

## Objetivo da Sprint

Caracterizar o dataset utilizado no trabalho antes das analises das questoes de pesquisa. Nesta etapa, o banco contem principalmente dados de descoberta de playlists e canais do YouTube, organizados por linguagem de programacao.
