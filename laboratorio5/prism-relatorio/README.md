# Projeto LaTeX para Prism

Este diretório contém um relatório LaTeX autocontido para importar no Prism.

Arquivos principais:

- `main.tex`: relatório completo.
- `referencias.bib`: referências bibliográficas.
- `figuras/tempo_ms.png`: gráfico de tempo de resposta.
- `figuras/tamanho_bytes.png`: gráfico de tamanho do payload.
- `dados/results.csv`: medições oficiais.
- `dados/validation_results.csv`: medições de validação.

No Prism, importe a pasta `prism-relatorio` e compile `main.tex`.
